# Amazon Sales Performance Dashboard

## Project Overview
An interactive sales analysis dashboard built using Microsoft Excel to explore sales performance across product categories, customer locations, payment methods, products, and order statuses.

## Objectives
- Analyze sales distribution across product categories.
- Compare sales across customer locations.
- Explore payment method usage.
- Understand order status distribution.
- Use interactive filters to explore sales data.

## Tools and Skills
- Microsoft Excel
- PivotTables and PivotCharts
- Data Analysis
- Data Visualization
- Interactive Slicers

## Dashboard Features
- Sales by Category
- Sales by Payment Method
- Order Status Analysis
- Sales by Customer Location
- Product-Level Sales Analysis
- Interactive filters for customer location, category, and product

## Workbook Contents
The Excel workbook includes the following worksheets:
- `Raw_Data` — Source sales records
- `Pivot Table` — Pivot-based summaries
- `Amazon Dashboard` — Dashboard visualizations
- `Data_Dictionary` — Column definitions
- `Case_Study_Tasks` — Analysis practice questions

## How to Use
1. Download `Amazon_Sales_Performance_Dashboard.xlsx`.
2. Open the workbook in Microsoft Excel.
3. Navigate to the Amazon Dashboard worksheet.
4. Use the slicers to filter the dashboard.
5. Explore the underlying PivotTables and source data.
